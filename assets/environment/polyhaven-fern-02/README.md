# Poly Haven Fern 02 - high vegetation tier

This folder contains the official **Fern 02** glTF from
<https://polyhaven.com/a/fern_02>, retained at the 4K source tier for sparse
High, Ultra, and Extreme forest-floor dressing. It is intentionally not a
forest-wide repeated asset: the runtime places a small number of non-colliding
clumps around the exterior boundary and extraction route, while Competitive Low
does not request or render them.

## Source and verification

- Official files API: <https://api.polyhaven.com/files/fern_02>
- License: [Creative Commons Zero 1.0 Universal](https://polyhaven.com/license)
- Source credits: Rico Cilliers (modeling) and Rob Tuytel (scanning)
- Runtime package: `fern_02_4k.gltf`, `fern_02.bin`, and the matching 4K
  albedo, ARM, and OpenGL-normal JPEGs.

The five staged runtime files were integrity-checked against the official API
metadata when this folder was added. The original downloaded archive is not
bundled.
