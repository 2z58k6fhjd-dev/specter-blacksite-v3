# Steel Frame Shelves 01 - runtime record

This directory contains the official browser-ready 2K glTF package for
**Steel Frame Shelves 01** by James Ray Cock from Poly Haven.

- Asset page: <https://polyhaven.com/a/steel_frame_shelves_01>
- Official file metadata: <https://api.polyhaven.com/files/steel_frame_shelves_01>
- License: CC0 1.0; see `LICENSE.txt` and <https://polyhaven.com/license>
- Runtime use: three instanced facility shelving props with collision and
  shadowing, loaded as optional set dressing. The game retains procedural props
  if this asset cannot download.
