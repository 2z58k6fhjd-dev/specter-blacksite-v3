SPECTER Operator Player Model
=============================

This player character is assembled at runtime by src/specter-operator.js. It uses
the existing rigged soldier asset as its animation-ready base and adds a custom
black-multicam material treatment, helmet equipment, headset and microphone,
plate-carrier magazines, radio and antenna, belt kit, holster, knee shells, and
subdued SPECTER insignia based on the project character turnaround supplied by
the project owner.

The underlying model remains licensed and credited under:
assets/soldier/license.txt

The source skeleton has 127 joints, including articulated fingers. Keep the
soldier license file with every redistribution of this derived player model.
