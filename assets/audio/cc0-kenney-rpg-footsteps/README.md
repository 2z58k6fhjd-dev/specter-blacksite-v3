# CC0 player footsteps

This folder contains ten unmodified footstep clips (`footstep00.ogg` through
`footstep09.ogg`) from the official [Kenney RPG Audio](https://www.kenney.nl/assets/rpg-audio)
pack by Kenney Vleugels / Kenney.nl.

- Official archive: `kenney_rpg-audio.zip`
- License: Creative Commons Zero 1.0 (CC0), preserved in `License.txt`
- Runtime use: varied first-person player steps; Web Audio filtering presents
  the same recordings as brighter indoor hard-floor steps or softer exterior
  grass steps.
- Fallback: a short procedural surface step remains active whenever a recorded
  clip cannot download or decode.

The original archive is retained only in the local research workspace. These
runtime clips are copied without editing; no unlicensed source masters are
bundled with the game.
